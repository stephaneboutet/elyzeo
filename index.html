● In development · macOS

Project Sandridge

A visual neural-network editor for the Mac. Build models by wiring nodes together, from data pipelines and architectures to training loops and live metrics. Everything trains natively on Apple silicon with MLX.

  • Drag-and-connect nodes, with nested sub-graphs you can open like tabs
  • Built-in data pipelines, optimizers and loss functions
  • Live CPU, GPU and MLX memory monitoring while you train
  • First milestone: a complete NanoGPT trained on Shakespeare
